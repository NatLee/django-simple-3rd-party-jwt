Django Simple 3rd Party JWT

Sign in with Google or Microsoft, get a Simple JWT access/refresh pair back.

$pip install django-simple-third-party-jwt
Google POST
/api/auth/google/token
body: {"credential": "…"}
Microsoft GET
/api/auth/microsoft/signin
Microsoft sign-in, back to …/callback
Your Django site
  • checks with Google / Microsoft
  • domain in VALID_REGISTER_DOMAINS
  • finds or creates the User
Simple JWT pair
accesseyJhbGciOiJIUzI1…
refresheyJhbGciOiJIUzI1…
Google: in the JSON response
Microsoft: in localStorage
Authorization: Bearer …
